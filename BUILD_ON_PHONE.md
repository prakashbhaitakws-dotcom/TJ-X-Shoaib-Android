# APK banane ka easiest tareeqa (phone se)

1. Is project ZIP ko GitHub par ek new repository me upload karein.
2. Repository me **Actions** kholen.
3. **Build Android APK** workflow select karke **Run workflow** dabayein.
4. Build complete hone ke baad workflow ke **Artifacts** section se APK download karein.
5. Android me APK install karein. Agar permission aaye to browser/file manager ko “Install unknown apps” allow karein.

GitHub Actions Android SDK aur Gradle khud setup karta hai; PC ki zarurat nahi padti.
